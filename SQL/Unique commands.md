* ***Time** - TIME(column_name), formats the column value into a time format HH:MM:SS
* ***CHAR_LENGTH(name)** - basically format string into a number per character, 99% of usage to find the longest string in a column.
* ==date >= '2005-01-01' AND p.date < '2006-01-01'== - use it for date ranges to not write long date formats.
